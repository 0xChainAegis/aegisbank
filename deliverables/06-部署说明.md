# AegisBank 部署说明（2026-10-31）

仅支持已验证的 Linux/WSL 本地模拟运行。后端使用 fcntl，不能直接宣称原生 Windows Python 可运行。全部金融数据是 Mock Bank Core。

## 1. 前置依赖

Python 3.11+（含 venv/pip）、符合 fronted/frontend/package.json engines 的 Node.js（含 npm）。一键入口会使用已有 uv/pnpm，或将缺失工具安装到本项目；使用冻结锁文件安装应用依赖。一键启动验证见[启动记录](../docs/ONE-COMMAND-START-2026-10-31.md)，业务验收见[收尾执行记录](../docs/CLOSURE-2026-10-31.md)。

## 2. 从源码启动

```bash
git clone https://github.com/0xChainAegis/aegisbank.git
cd aegisbank
bash start.sh
```

入口自动组装、安装依赖、首次初始化 .runtime/backend/data/quickstart.db；已有库直接保留，不做重置。前后端、Vite代理及审计检查通过后打开银行助手，Ctrl+C 同时关闭本次服务。无图形环境使用 `bash start.sh --no-browser`；也可用 `--database /绝对路径/rehearsal.db` 指定模拟库。

一键入口固定离线规则 Planner、关闭后台自动任务并开启沙箱。需要模型或开发热重载时使用[贡献指南](../CONTRIBUTING.md)中的手动启动流程。首次安装依赖需要网络；预置工具安装在 .runtime/.launcher-tools/，不修改系统全局工具。

端口8000/5173被占用或同仓库已有启动进程时明确拒绝，不终止其他服务。日志保存在 .runtime/launcher-logs/ 对应运行目录。手动重置仍须停掉后端，并保留所需审计证据；一键入口不会自动重置数据库。

## 3. 演示前检查

```bash
curl -fsS http://127.0.0.1:8000/api/health/ready
curl -fsS http://127.0.0.1:8000/api/audit/verify
```

readiness 必须为 ready，审计必须 valid=true。未就绪时不尝试写入；前端只通过 /api 代理访问后端。演示 OTP 246810、模拟生物识别 FACE-888888 仅用于本地流程展示。

## 4. 离线与现场失败处理

默认 rule Planner 不需要密钥，不调用外部模型。依赖应在演示前安装好；无网络的现场不重新安装。模型未配置不影响已支持的离线代表场景，但不得把规则结果称为真实模型成绩。

端口占用时先识别已有服务，不终止未知进程。出现旧确认 409、过期或撤权时重新发起并确认；不得改库绕过。UNKNOWN 先核对账务与审计，禁止重复点击或自动重试。需要重录时停止本次演示服务、明确重置独立演示库、重新启动并检查 ready 与审计链。

## 5. 提交包与生产边界

源码包含六职责包、组装脚本、README、文档和测试，不包含 .runtime、依赖目录、真实配置、凭据及运行数据库。技术/安全 Word/PDF、答辩 PPT 和作品简介位于 current/；视频与正式上传由人工完成。

没有生产身份、真实 MFA、真实 IM、OS 级沙箱、分布式幂等或高可用承诺。

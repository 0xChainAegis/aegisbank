## 1. 冻结依赖与全量回归

```bash
python3 scripts/assemble.py
bash scripts/check.sh lint

```

test 同时覆盖根组装器、后端 pytest、前端 Vitest；scenarios 覆盖六场景和审计。测试失败不得通过删断言或缩减范围关闭。

## 2. 离线 NLP 复现

```bash
mkdir -p /tmp/aegisbank-eval
.runtime/backend/.venv/bin/python scripts/evaluate-u1.py --corpus NLP/backend/evals/nlp/u1-development.json --split development --require-verified --output /tmp/aegisbank-eval/development.json
.runtime/backend/.venv/bin/python scripts/evaluate-u1.py --corpus NLP/backend/evals/nlp/u1-heldout.json --split heldout --output /tmp/aegisbank-eval/heldout.json
```

保留集存在失败样本；运行成功不代表全部语义正确。金标仍需人工复核，不改动冻结语料与划分。真实模型按用户决定暂缓，not_run 不计为模型成绩。

## 3. 真实浏览器自动联调

```bash
# 需要 Windows Edge 与 WSL 互通，8000/5173 空闲；每次使用新标签
U4_EVIDENCE_LABEL=local-desktop node scripts/u4-browser-e2e.mjs
U4_EVIDENCE_LABEL=local-mobile U4_VIEWPORT_WIDTH=390 U4_VIEWPORT_HEIGHT=844 node scripts/u4-browser-e2e.mjs
```

脚本创建全新临时 SQLite，不复用未知服务；显式提供已存在的 U4_DB_PATH 会被拒绝，避免删除已有数据库。它经真实 Chromium、Vite 代理和 FastAPI 验证补槽、修订、旧确认 409、最终一笔 300 元转账和历史回读，并保存 JSON 与截图。默认历史标签仅为兼容旧命令，新运行应显式使用新标签。

这是 CDP 自动交互与 CSS 视口检查，不是人工手机、物理键盘或读屏验收，不替代非实现者独立签署。

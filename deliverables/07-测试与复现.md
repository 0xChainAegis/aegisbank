### 1.2 信任层 17 条覆盖的 12 类矩阵

`test_trust.py` = 12 类矩阵 + 5 条补充（readiness 正向、可读 422、模型冲突 2 条、连续失败熔断）。

1. ActionEnvelope 参数被篡改 → 拒绝执行；
2. Envelope 过期 → 拒绝；
3. nonce 复用 → 拒绝；
4. 确认后撤权 → 执行前复检阻断；
5. 重复提交同一请求 → 只产生一次执行（幂等）；
6. 执行结果未知 → 状态 `UNKNOWN` 且不重复执行；
7. readiness 未就绪 → 写操作 fail closed；
8. 注入命中 → 整条请求拒绝、无可执行计划；
9. 模型试图覆盖用户金额/收款方 → 白名单拦截；
10. 证据分层字段在 API 与审计中完整出现；
11. 状态机非法迁移被拒；
12. 新增证据字段后审计哈希链仍校验通过。

- 五阶段为 `encoding / lint / build / test / security`；`lint/build/test` 来自 `.dsh-project.json` 的 `stages`，`encoding/security` 由 gate 内置执行。
- **纯文档改动**（只有 `docs/`、`deliverables/` 等）时，gate 会按 docs 快速通道把 `test` 标为 `skip`，整体返回 `unverified`（退出码 2）。这是设计行为，不是测试失败；要复现「五阶段 PASS」，请在含源码改动的树上运行，或在干净工作树/独立副本运行。
- 若 `security` 报 HIGH，先处理密钥/凭证再提交；不要把演示 OTP 或 token 写进真实配置。

## 5. 边界与未覆盖项（诚实清单）

1. **阶段 2.5 人工体验测试已推迟**：`docs/UX-DOGFOODING.md` 是待执行清单；截至 `75df12b` 没有 `docs/UX-RECORD.md` 的三轮验收记录。本文的「可复现」指自动化测试与脚本，不等于已完成真实用户 Dogfooding。
2. **无真实银行系统**：所有账户、卡片、账单、交易、订阅、理财、转账均为 Mock Bank Core 的 SQLite 模拟数据；不连接支付网络，不产生真实资金变动；理财内容不构成投资建议。
3. **无真实 MFA / 真实身份认证**：OTP `246810`、`FACE-888888`、`approval_token` 都是演示值；`X-Aegis-Role` 由客户端自报，服务端不验证调用者身份。
4. **无真实 IM 平台**：`im / cli / webhook` 适配器不绑定平台签名、租户或用户映射；`sender_id` 只写入审计。
5. **沙箱是进程内演示级**：socket 级网络阻断、线程超时（Python 线程无法强杀）、入参 8 KB / 出参 64 KB、可选白名单；不是 OS 容器/命名空间/强制资源配额。
6. **幂等键与 nonce 无 TTL 清理**：`Idempotency-Key`、`used_nonces`、`im_messages` 会持续增长；生产需要过期与归档策略。
7. **熔断为系统级计数**：单库单实例，未按用户隔离；多租户/分布式部署需要重做计数与冷却。
8. **多轮上下文与指代消解未实现**：Planner 目前以单轮指令为主；「它」「刚才那笔」等指代不在保证范围内。
9. **定时任务是演示实现**：`scheduled_tasks` + `POST /api/automation/run-due` 时间快进 + 可选后台轮询，不是常驻 cron，也不是跨进程分布式调度。
10. **SQLite 单机持久化**：不满足银行级高可用、隔离、容灾与 WORM 审计要求。
11. **前端无浏览器级 E2E**：22 条 Vitest 覆盖视图模型/格式化/角色与 2A 文案，不覆盖真实点击、网络时序、无障碍与跨浏览器；也没有覆盖率百分比门禁。
12. **安全测试非渗透测试**：注入检测、权限网关、ActionEnvelope、幂等与哈希链是基线；未做专业渗透、SAST/DAST、限流、CSRF/mTLS、OS 级隔离。
13. **LLM 为可选依赖**：默认规则 Planner 完全离线；接入 OpenAI-compatible 模型时仍经同一 Compiler、候选白名单、风险引擎与网关，但未做模型质量/提示词回归评测。

> 对外表述建议：**「六个参考场景已完整覆盖（6/6）：典型能力可用自然语言发起，风险分级正确，审计可见，前端可展示；所有数据为模拟数据。阶段 2A 六项已落地。生产化边界见上。」** 不要写「生产级银行 Agent」或「真实银行接入」。

## 6. 复现失败排查清单

| 现象 | 优先检查 | 处理 |
|---|---|---|
| `Address already in use` / 8000 或 5173 打不开 | 端口占用、旧进程 | `ss -ltnp \| grep -E '8000\|5173'`；结束旧进程；或换端口并同步前端代理。 |
| `uv: command not found` | 不在 WSL、PATH 不含 `~/.local/bin`、未安装 | `wsl -d Ubuntu-24.04`；`command -v uv`；`bash scripts/bootstrap.sh`；必要时 `export PATH="$HOME/.local/bin:$PATH"`。 |
| `pnpm: command not found` / Node 版本不对 | Node < 20.19 或 < 22.12 | `node -v`；安装 Node 20.19+/22.12+；`pnpm install`。 |
| `database is locked` | 后端仍在运行；并发测试/seed | 停后端；再 `bash scripts/seed-demo.sh`；不要在后端运行时删库。 |
| `seed-demo.sh` 后没有 3000 元虚拟卡 | 后端指向了别的库（常见：`dev.sh` 默认库） | 检查 `AEGIS_DATABASE_PATH`；确认指向 `backend/data/dogfood.db`；重启后端。 |
| 页面能开但按钮灰 / 写操作 503 | readiness 非 `ready` | `curl /api/health/ready` 看四个组件；重启后端；必要时停后端 → seed → 启动。 |
| 红色操作一直要求 OTP / 确认过期 | 未输 `246810`；确认 TTL 300 秒已过 | 重新发起任务；在 5 分钟内完成确认；不要复用旧弹窗。 |
| 撤权后所有转账都失败 | 镜头/演示后忘记恢复 `transfer` 授权 | 04 权限控制台点「授予」；或重置数据。 |
| 时间快进执行 0 条 | 生日礼物未到期；UI 按钮不带 `now` | 用 `run-due?now=<未来时间>`；检查 02 页 `run_at`；或 +400 天快进。 |
| 审计校验 `valid=false` | 手工改库、旧库残留、并发写坏链 | 停后端 → seed → 启动；不要手工改 `audit_entries`；重跑 `scenario-check.py` 验证。 |
| pytest 收集不到用例 | cwd 不对、`pythonpath` 未生效 | 在 `backend/` 下运行；确认 `pyproject.toml` 的 `testpaths=["tests"]`；`uv sync`。 |
| 前端测试/类型检查失败 | 依赖版本漂移、`node_modules` 损坏 | `pnpm install`；`pnpm typecheck`；删除 `node_modules` 重装。 |
| gate 返回 `unverified` | 仅文档改动导致 `test=skip` | 这是设计行为；在含源码改动的树或干净工作树跑全量；或明确用 `-Unverified -Reason` 降级提交。 |
| gate security 报 HIGH | 误把演示 token/密钥写入文件 | 移除真实凭证；演示值只放在代码/文档明确标注的位置；重跑扫描。 |
| WSL 端口在 Windows 打不开 | WSL 端口转发/绑定地址 | 后端用 `--host 0.0.0.0`；前端 `pnpm dev --host 0.0.0.0`；先试 `http://localhost:5173`。 |

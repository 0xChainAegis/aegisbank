## 2. 四个工作包

- [ ] 人工复核现有 304 条 AI 辅助金标，关闭争议，记录复核人、裁决和数据版本；保持开发/保留集的表达家族隔离，已查看的失败样本不得再宣称为未见样本。
- [ ] 冻结真实模型版本与配置，复用 `scripts/evaluate-u1.py --real-model` 完成 `existing_llm` / `semantic_llm` 对照；与已有 `p0_rules` / `p1_semantics` 分开报告。记录参数匹配、完整计划、漏步骤/条件保留、必要/非必要澄清、安全误写，以及 p50/p95 延迟、超时、调用量和实际成本；多轮结果引用 U2/U4，不另建平台。

验收：保留原始响应与失败清单，修复已声明支持范围内的阻断问题；安全反例业务误写为 0。现有保留集 116/148（78.38%）仅为历史基线，95% 是原计划候选目标、不是比赛硬门槛；不重调保留集凑分。人工复核或真实模型未完成时，U1 继续标注未完成。

### B. 独立人工体验验收

- [ ] 由非实现者连接真实本地服务端，从页面完成“给妈妈转钱 → 五百 → 改成三百 → 旧确认失效 → 重新确认 → 我刚才转了多少/转给谁”。核对新金额、`plan_hash`、草稿版本、新 nonce 与回执一致；数据库最终仅一笔 300 元 Mock 转账，旧确认返回 409。
- [ ] 在桌面及 390px 宽度完成主链路；用键盘检查补槽、修订、确认、焦点循环/恢复和屏幕阅读器标签，并检查长姓名、大金额、长错误原因。只修复阻断理解或操作的问题。
- [ ] 合并检查重复提交/重试、刷新恢复、过期、版本冲突、跨用户、撤权、not-ready、离线、失败及 UNKNOWN：不重复扣款、不越权、不显示虚假成功；用户 A 看不到 B 的草稿或回执。已有后端用例复用，仅补缺失的实际界面证据。

验收：保存版本、操作步骤、业务状态和截图；前端单测或自动浏览器证据不能替代本次独立人工结论。

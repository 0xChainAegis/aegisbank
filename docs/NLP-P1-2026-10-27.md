## 交付范围

P1 工程实现已落地：`SemanticFrame/v1` 与服务端 `SemanticAnalysis/v1` 分离，场景注册意图与实体目录，确定性验证原文跨度、槽位、金额、日期、实体唯一性和否定作用域。条件、顺序、遗漏片段与缺失槽位进入候选契约，未支持时澄清。受限的原有金额补充续问保持可用。

模型适配器只提交语义候选，不接收银行事实目录，不产生工具、风险或授权。默认离线规则；配置 llm/auto 可接 OpenAI-compatible 服务，但本轮只用 MockTransport 验证适配协议，没有真实模型效果结论。模板转换沿用原 Planner 生成 DAG，再检查允许工具序列。相较 P0 的新收益是口语覆盖、可审查的语义来源和一致的本地验证边界。

执行链保持 Compiler、动态风险、权限网关、分级确认、ToolExecutor/SandboxGuard 和审计。语义报告参与 plan_hash；确认复算包含该报告。篡改内容或非法契约返回 409，不产生扣款；实体读取失败不能猜测对象，readiness 失败仍为 503。

## 对照结果与局限

[开发语料](../NLP/backend/evals/nlp/p1-regression.json)共 **41 条**，包含 24 条正向和 17 条澄清/拒绝。脚本分别以 `semantic_enabled=false/true` 比较同一 P0 规则实现和 P1 包装器。指标只核对工具序列、已标注的首步参数及负向是否无计划；不是完整 DAG 语义正确率，未标注参数不计入正确性结论。

| 模式 | 正向匹配 | 负向澄清/拒绝匹配 | 总匹配 |
|---|---:|---:|---:|
| P0 规则 | 7/24 | 12/17 | 19/41 |
| P1 默认离线 | 24/24 | 17/17 | 41/41 |

[逐项结果](../NLP/backend/evals/nlp/p1-report.json)保存语料 SHA-256、HTTP 状态、工具序列与语义状态。语料与模板共同开发，不能当成保留集；也不能由此声称准确率 100% 或任意自然语言完整理解。

额外的 [12 条评审改写探针](../NLP/backend/evals/nlp/p1-review-probes.json)来自独立评审，但评审已接触开发语料与部分模式，**不属于盲测**。最终 [探针结果](../NLP/backend/evals/nlp/p1-probe-report.json)：P1 7/12 匹配，其中 1 条语义 verified、6 条 legacy，另外 5 条澄清；P0 同为 7/12。评审发现的“买入”分词问题已修复，因此该探针也成为开发反馈。运行以下命令会按尚未全匹配返回 **退出码 1**，这是覆盖缺口报告，不是已通过的门禁项目：

```bash
.runtime/backend/.venv/bin/python scripts/evaluate-nlp.py \
  --corpus NLP/backend/evals/nlp/p1-review-probes.json
```

结论：P1 有界工程交付与回归闭环完成；原计划“六场景没出现过的同义表达均生成语义等价计划”的泛化验收**尚未完成**。应先构建按表达家族隔离的人工标注保留集，再评估真实模型的正确性、拒绝率、延迟和成本，不能用扩写模板后的同一语料替代泛化验证。

## 仍未实现或未验证的边界

1. 写操作和查询的 P1 verified 路径必须符合可独立核验的已注册表达；仅有关键词或模型全文跨度不足以证明完整理解。未迁移表达沿用 P0，报告为 legacy，不能视为已验证语义。
2. 自由多任务 DAG、任意条件分支和跨场景组合仍未实现；保留既有预置生日联动和账单清理模板。不支持的组合/条件请求澄清，不执行部分写动作。
3. 通用多轮槽位填充、指代消解、纠错、版本冲突和授权重建属于 P2；本轮只保留既有绑定用户/角色、10 分钟、单次消费的受限续问。
4. 日期以 UTC 为参考；“明天”等尚无按用户时区解析。只支持 CNY；当前账户/月份默认值标为 demo_policy，不伪装为原文事实。
5. 实体选项出现在 API 语义报告中，尚无专门的前端候选选择和语义解释面板。真实模型效果、开放表达泛化、基准评测与展示工作未完成。
6. 真实银行、身份认证、生产 MFA、真实 IM 和 OS 级沙箱仍未接入；金融结果均为 Mock。没有升级为生产银行系统。

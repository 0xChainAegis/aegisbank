## 已关闭的缺口

1. **全句未识别时的旧规则旁路。** 原先“我不想给妈妈转500元”“给妈妈转500元要等工资到账”“给妈妈转500元后给爸爸发条短信”可能只生成转账。新增 `semantic_legacy.py`：对旧表达按完整白名单准入，并复核金额、实体、日期、卡片和预置 DAG；未知前后限定与附加任务不得执行已命中部分。读取失败拒绝准入，原有无步骤澄清保留。
2. **无工具名的 arguments 旁路。** 非空 arguments 不再直接进入显式模式。自然语言和补充参数共同验证，所有补充字段必须匹配最终计划。保留“分析我的本月账单”加已匹配 account_id 的旧 API，用错账户或 unused 字段须澄清。显式 tool_name 仍使用原独立结构化 API 契约与执行保护。
3. **语义槽位到动作参数可能丢失。** 场景声明 `bindings`，每个槽位必须有参数目标，编译后再次核对。定时联系人绑定实际 to_account；普通联系人按工具的 to_phone / to_name 选择顺序验证，无手机号也可用。金额变成其他数值、格式损坏、日期或对象不一致均停止规划。
4. **语言覆盖缺口。** 补充有界的礼貌语、汇款/打款、货币前缀、消费复盘、理财词序、卡片指称、还款日同义、停止自动续费，以及生日/账单清理预置联动。没有把未知词、未覆盖尾句作为无害文字略过。
5. **上海午夜日期不一致。** P1 月份与相对日期、旧定时规划、兼容复核和生日日期使用 Asia/Shanghai 的业务日期；旧 UTC 语义报告仍可读取。定时工具已有默认执行时刻仍为 09:00 UTC（北京时间17:00），并非新增任意时分理解。
6. **超限与澄清回退。** 超过 frame 分句上限时整体澄清，不截断执行或暴露内部校验错误；已理解的卡片操作在对象未知时保留业务 intent 和当前用户有效候选。

所有金融结果仍来自 Mock。规划和实体身份元数据解析不执行金融工具；业务执行、补偿、风险、权限、MFA、Envelope、幂等、沙箱和审计继续走原统一链路。

## 未实现或未验证的边界

- 真实 LLM 的语义效果、延迟、成本及生产数据表现未测；模拟协议测试不替代真实模型评测。
- 超出已注册语法与完整兼容白名单的表达继续澄清；legacy 不等于逐槽位验证，正式开放表达泛化验收仍未完成。
- 通用多轮记忆、指代与纠错为 P2；任意条件、自由多任务和通用 DAG 组合为 P3。当前只开放原有两类预置联动。
- 前端完整语义解释和候选选择面板、正式效果展示为后续范围。本轮未重做前端。
- 只支持 CNY 与上海业务日期；任意用户时区、任意执行时分、换汇仍未实现。
- 真实银行、生产身份/MFA、真实 IM 和 OS 级沙箱仍未接入。

`AEGIS_SEMANTIC_ENABLED=false` 仅回退旧 P0 规划，不关闭执行权限链。关闭后不具备本轮完整表达门禁，不应使用该模式宣称 P1 语义能力或安全性。

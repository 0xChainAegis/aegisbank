## 截取要求

1. 先启动服务：`bash scripts/dev.sh`，打开 <http://127.0.0.1:5173>。
2. 使用 `demo-user` 与默认 Mock Bank Core 数据，页面应显示演示数据标记。
3. 截取完整浏览器内容区域，保留页面标题和关键状态，不要只截局部弹窗。
4. 隐藏书签栏与无关浏览器 UI；不要出现真实姓名、手机号、真实银行卡号、真实邮箱或本地敏感路径。
5. 优先 PNG；浏览器工具原生输出的 JPEG 可直接保留，不改变截图内容。文件名必须与上表一致，README 直接引用这些路径。
